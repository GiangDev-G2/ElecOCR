# Visual review checklist

- Upload, primary action and reading are identifiable within three seconds.
- Only one primary action is visually dominant.
- Style matches `Calm · Glass · Precision`; glass never reduces readability.
- No background image, decorative gradient, fake desktop window or nested glass stack.
- Reading uses tabular numerals and preserves leading zeros.
- Original image, detected region and recognition crop are large enough to inspect; fallback appears only when executed.
- `ok`, `review_required`, `unreadable`, `error`, loading and offline are distinct without color alone.
- Shadows use only approved tokens.
- No page-level horizontal scrolling at supported widths.
- Keyboard focus, labels, contrast and reduced motion work in light and dark themes.
- React components use semantic HTML and expose stable accessible roles/names for tests.
